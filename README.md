# Mini Chatbot SharePoint

A mini chatbot RAG connected to a mock SharePoint

## Goals

- Demonstrate my skills in Golang and Python : SOLID & POO without Agent IDE
- Creating a RAG ACL with in memory documents pdf.
- Using Telemetry for the LLM.
- Pre-Production to simulate production use.

## Stack

- Golang 1.25
- Python 3.14
- Ollama : Open Source LLM and Embedding Model
- Milvus
- Langchain, Langfuse
- Centry
- Graphana
- Prometheus
